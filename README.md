# Telegram-бот «Симулятор стартапа»

Полноценный Telegram-бот-игра на Python 3.11+ и aiogram 3.x. Игрок создаёт стартап, выбирает нишу, управляет деньгами, репутацией, продуктом, командой и маркетингом, переживает случайные события, покупает улучшения и попадает в лидерборд.

## Возможности

- регистрация пользователя через `/start`;
- создание нового стартапа с выбором названия и ниши;
- сохранение прогресса игры в SQLite;
- полный игровой цикл на 30 дней;
- действия через inline-кнопки;
- 20 случайных игровых событий;
- магазин постоянных улучшений;
- профиль игрока и экран статистики;
- лидерборд по итоговому score;
- финальные условия победы и поражения;
- админ-панель: статистика, выдача денег, сброс игры, рассылка.

## Стек технологий

- Python 3.11+
- aiogram 3.x
- SQLite
- SQLAlchemy 2.x ORM
- Alembic
- python-dotenv
- logging
- FSM

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Настройка окружения

1. Скопируйте пример файла окружения:

```bash
cp .env.example .env
```

2. Заполните переменные:

```env
BOT_TOKEN=ваш_токен_бота
ADMIN_ID=123456789
DATABASE_URL=sqlite+aiosqlite:///./startup_simulator.db
```

## Создание базы данных

### Вариант 1: быстрый старт

При запуске `app/bot.py` таблицы создадутся автоматически, а базовые улучшения будут заполнены.

### Вариант 2: через Alembic

```bash
alembic upgrade head
```

После этого при первом запуске бота справочник улучшений автоматически заполнится.

## Запуск бота

```bash
python -m app.bot
```

Бот работает в режиме long polling.

## Игровые команды

- `/start` — регистрация и приветствие;
- `/help` — помощь;
- `/play` — начать или продолжить игру;
- `/profile` — полный профиль стартапа;
- `/stats` — краткая статистика;
- `/top` — лидерборд;
- `/admin` — админ-панель;
- `/reset` — подтверждённый сброс игры.

## Как устроена игра

- у игрока есть деньги, репутация, клиенты, уровни продукта, команды, маркетинга, риск и дни;
- каждый ход можно выбрать действие;
- на следующем дне считается экономика и происходит случайное событие;
- при покупке улучшений бонусы сохраняются в БД;
- победа достигается ростом клиентов, денег и репутации или сильным финальным score;
- поражение наступает при банкротстве, критическом риске или потере репутации.

## Админ-функции

Администратор определяется по `ADMIN_ID` из `.env`.

Доступно:
- просмотр количества пользователей;
- просмотр количества активных игр;
- выдача денег пользователю по Telegram ID;
- сброс игры пользователя;
- рассылка сообщения всем зарегистрированным пользователям.

## Полезные замечания

- Игра сохраняется между перезапусками.
- Если у пользователя уже есть активный стартап, бот предлагает продолжить игру.
- Все основные сущности хранятся в SQLite через SQLAlchemy ORM.
- Код разделён на понятные слои: handlers, services, models, database, keyboards.
